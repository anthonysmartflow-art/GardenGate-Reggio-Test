# Garden Gate — Reggio-direction homepage test

This is an unapproved Stage 7 comparison test, not the selected homepage, final copy, final design system, a production website, or a Stage 8 rendition.

## Run locally

```bash
npm install
npm run dev
```

For the verified production build:

```bash
npm run build
npm run preview -- --host 127.0.0.1 --port 4171
```

## Scope

- One responsive homepage from header through footer
- No deeper pages, CMS, forms, donation processing, analytics, authentication, deployment, or production behavior
- Internal links preserve the locked destination values but their deeper pages are intentionally not built
- Donate links hand off directly to `https://www.gardengatemv.org/donate`
- Em Português remains visible, inactive, and unlinked
